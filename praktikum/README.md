# Практикум «Анализ целесообразности предпринимательской деятельности» — извлечённые материалы

В этой папке:
- **kalkulyator_testov.html** — единый HTML-калькулятор всех 9 тестов практикума: выбираешь тест, отвечаешь на те же вопросы (дословно из форм), результат и интерпретация считаются мгновенно. Есть вкладки «Интегральная оценка» (Ур) и «Сводный отчёт» (все показатели + печать в PDF). Ответы сохраняются в браузере (localStorage). Работает офлайн — просто открыть файл.

- **test2_4_extracted.md** — дословное полное содержимое теста 2.4 (включая скрытую страницу «Вывод по тесту 2.4»).

### Часть 3. Анализ предпринимательского потенциала
| Тест | Содержание | Подсчёт | Интерпретация (из формы) |
|---|---|---|---|
| **3.1 Физическая работоспособность** | ФИО; 1 вопрос × 3 характеристики состояния | Уфр = 2/1/0 | «запишите баллы для интегральной оценки» |
| **3.2 Тревожность (Тейлор–Немчинов)** | ФИО; 50 утверждений да/нет (опечатки формы: «нент», «нгервно», №48 = №14) | сумма тревожных баллов 0–50 | Унр=0 высокий (25–50); Унр=1 средний (5–25); Унр=2 низкий (0–5). Зафиксируйте результат |
| **3.3 Состояние здоровья** | ФИО; 5 вопросов о заболеваниях × 3 варианта | сумма 0–10 (варианты 0/1/2) | Уз=2 (9–10, абсолютное здоровье); Уз=1 (6–8, среднее); Уз=0 (4–5, плохое) |

### Интегральная оценка (скрытые страницы теста 3.3)
**Ур = (Уфр + Унр + Уз) / 6 × 100%** (в форме — картинкой с формулой)
1. Если одно из значений (Уфр/Унр/Уз) = 0 → предпринимательская деятельность **противопоказана**.
2. Если Ур ≥ 50% → допустима **с ограничениями** (с учётом факторов здоровья).
3. Если Ур = 100% → возможна **без всяких ограничений**.

## Допущения калькулятора (ключи баллов)
Формы публикуют метки баллов («3 балла», «5 баллов», «18 points», «1 балл») и тексты выводов, но не публикуют ключи ответов. В калькуляторе использованы:
- тесты 1, 2, 3.1 — варианты 2/1/0 (метка «3 балла» = 2+1+0; формулы ×10 и ×5 дают максимум 100%);
- тест 2.1 — классический ключ КОС: «да» = 1 балл на вопросы 1,3,5,7,9,11,13,15,17,18,19,20; «нет» = 1 балл на 2,4,6,8,10,12,14,16;
- тест 2.2 — классический ключ КОС: «да» = 1 балл на 1,3,5,7,9,11,13,15,17; «нет» = 1 балл на 2,4,6,8,10,12,14,16,18,19,20;
- тест 2.3 — «да» = 5 баллов;
- тест 2.4 — 10/5/3 за первый/второй/третий вариант (из «18 points» и диапазонов 60–200);
- тест 3.2 — классический ключ Тейлора–Немчинова: «нет» на 1–13 и «да» на 14–50 = тревожный балл; границы диапазонов формы пересекаются (5 и 25) — калькулятор: 0–5 низкий, 6–24 средний, 25–50 высокий;
- тест 3.3 — 0/1/2 за варианты (сумма < 4 → Уз = 0, в форме не описано).
